# VMS Smart Card Bridge (Android App) 📱💳

แอปพลิเคชัน Android สำหรับเชื่อมต่อเครื่องอ่านบัตรประชาชน Smart Card (พอร์ต Type-C / USB OTG) เข้ากับระบบบันทึกผู้มาติดต่อ (VMS) บน Google Apps Script และ Supabase

---

## 🌟 ฟังก์ชันการทำงาน

1. **อ่านข้อมูลชิปบัตรประชาชนไทย 100%:**
   - เลขบัตรประจำตัวประชาชน 13 หลัก
   - คำนำหน้า, ชื่อ, นามสกุล (ภาษาไทย และ ภาษาอังกฤษ)
   - ที่อยู่ตามทะเบียนบ้าน (แปลงรูปแบบให้อ่านง่ายอัตโนมัติ)
   - วันเกิด, เพศ, วันออกบัตร, วันหมดอายุ
   - **ภาพถ่ายหน้าตรงดิจิทัลความละเอียดสูงจากชิปการ์ด**
2. **เสียบปุ๊บ อ่านปั๊บทันที (Auto Card Detection):**
   - มีระบบ Background Polling ตรวจจับการเสียบบัตรอัตโนมัติ ไม่ต้องคอยกดปุ่ม
   - เมื่อเสียบบัตร ระบบจะอ่านและกรอกข้อมูลลงฟอร์มหน้าเว็บ Google Apps Script ให้ทันทีใน 1-2 วินาที
3. **ใช้หน้าเว็บเดิม 100% (Hot-reloadable):**
   - หน้าตา UI ของ รปภ. ดึงจาก Google Apps Script URL ตัวล่าสุดเสมอ
   - หากมีการแก้ไขโค้ด HTML หรือฟังก์ชันบนเว็บ แอปในมือถือจะได้รับเวอร์ชันใหม่ทันทีโดยไม่ต้องลงแอปใหม่
4. **โหมดคู่ (Dual-Mode Fallback):**
   - หากไม่ได้ต่อเครื่องอ่านบัตร รปภ. ยังคงแตะถ่ายรูปบัตรประชาชนเพื่อใช้ Gemini AI OCR ได้เหมือนเดิม

## 🚀 สถาปัตยกรรมระบบ

```
[ บัตรประชาชนไทย ]
       │ (เสียบลงเครื่องอ่าน)
       ▼
[ เครื่องอ่านบัตร Type-C (USB CCID) ]
       │ (USB OTG Protocol)
       ▼
[ Android App: VMS Smart Card Bridge ]
  ├── CcidCardReader.kt      --> จัดการการสื่อสาร USB Bulk Transfer (Class 11)
  ├── ThaiIdCardParser.kt    --> ส่งคำสั่ง APDU และถอดรหัส TIS-620 + รูปถ่าย JPEG
  └── MainActivity.kt        --> รัน WebView แบบเต็มจอ และส่งข้อมูล JSON ผ่าน Javascript Interface
       │
       ▼ (window.onSmartCardRead)
[ หน้าเว็บ Google Apps Script (index.html) ]
  └── หยอดชื่อ, เลข 13 หลัก, ที่อยู่, แสดงรูปถ่ายหน้าตรง และบันทึกเข้า Supabase
```

## 🛠️ ขั้นตอนการสร้างไฟล์ติดตั้ง (.APK) ด้วย Android Studio

### สิ่งที่ต้องมี:
- คอมพิวเตอร์ที่ติดตั้งโปรแกรม **[Android Studio](https://developer.android.com/studio)** (ดาวน์โหลดฟรี)

### วิธีการ Build APK (ทำเพียงครั้งเดียว):
1. เปิดโปรแกรม **Android Studio**
2. เลือกเมนู **Open** แล้วเปิดโฟลเดอร์นี้:
   ```text
   c:\Users\jirasak.sa\Desktop\Smart Card Reader\android-smartcard-bridge
   ```
3. รอให้ Android Studio ทำการดาวน์โหลดและ Sync Gradle ให้เสร็จสิ้น (จะสังเกตแถบสถานะด้านล่างขวา)
4. ไปที่เมนูด้านบน:
   **Build** > **Build Bundle(s) / APK(s)** > **Build APK(s)**
5. เมื่อเสร็จแล้ว จะมีการแจ้งเตือนมุมล่างขวา ให้คลิกที่คำว่า **locate**
   (ไฟล์จะอยู่ที่โฟลเดอร์ `app/build/outputs/apk/debug/app-debug.apk`)
6. ส่งไฟล์ `app-debug.apk` นี้เข้ามือถือ Android ของ รปภ. (ผ่าน LINE, Google Drive หรือสาย USB)

## 📱 วิธีติดตั้งและใช้งานบนมือถือ Android

1. แตะเปิดไฟล์ `.apk` บนมือถือเพื่อติดตั้ง (หากมือถือแจ้งเตือนเรื่อง Unknown Sources ให้กดยินยอมให้ติดตั้ง)
2. **เสียบเครื่องอ่านบัตร Type-C เข้ากับพอร์ตชาร์จของมือถือ**
   * *หมายเหตุ: มือถือบางรุ่น (เช่น OPPO, Vivo, Realme) อาจต้องเข้าไปเปิด "OTG Connection" ในเมนู Settings > Additional Settings ของมือถือครั้งแรก*
3. หน้าจอมือถือจะเด้งถาม:
   > *"อนุญาตให้ จุดตรวจ รปภ. เข้าถึงอุปกรณ์ USB นี้หรือไม่?"*
   - ให้ติ๊กถูกที่ช่อง **"เปิดใช้เสมอสำหรับอุปกรณ์นี้"** แล้วกด **ตกลง (OK)**
4. เปิดแอป **จุดตรวจ รปภ.** ขึ้นมา:
   - แถบสถานะด้านบนจะแสดงไฟสีเขียว: **"พร้อมอ่านบัตร (เสียบบัตรได้เลย)"**
5. **เสียบบัตรประชาชนของผู้มาติดต่อเข้าเครื่องอ่าน:**
   - ภายใน 1-2 วินาที ข้อมูลชื่อ-สกุล, เลข 13 หลัก, ที่อยู่ และรูปถ่ายจะปรากฏขึ้นในฟอร์มทันที!
6. รปภ. สแกน QR บัตรคล้องคอ และกด **"ยืนยันการบันทึกเข้า (Check-in)"** ตามปกติ
